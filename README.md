# 📊 Sales Dashboard (Power BI)

## 🚀 Project Overview

This project presents a professional sales dashboard built using Power BI. It provides insights into revenue trends, customer behavior, and product performance.

## 📌 Key Features

- KPI Cards (Revenue, Orders, AOV, Customers)
- Sales Trend Analysis
- Top Products & Customers
- Revenue by Country
- Interactive Filters (Date, Product, Country)

## 🛠 Tools Used

- Power BI
- Python (Data Cleaning)
- Pandas
